# BarksBuds App Store / Google Play prep

This folder is the $0 store-prep work for wrapping BarksBuds as iPhone and
Android apps with Capacitor. Nothing here creates accounts, spends money, or
ships a build. The native project lives in `/app`.

| File | What's in it |
| --- | --- |
| [mike-checklist.md](mike-checklist.md) | What Mike has to do himself (accounts, keys, signing) |
| [listing-copy.md](listing-copy.md) | App name, subtitle, description, keywords, categories |
| [screenshots.md](screenshots.md) | Required screenshot sizes and suggested shots |
| [data-safety.md](data-safety.md) | Google Play Data safety and Apple privacy nutrition answers |
| [android-build.md](android-build.md) | How to build a debug APK once a JDK and SDK are available |

The public privacy policy is already live at `/privacy` and was updated for
the app (location, camera, notifications). Review that page before submitting.
