# Store screenshot list

Take these on a real device or an emulator once a debug / TestFlight build
exists. Use Lily as the only sample dog. No surnames, no other dogs, no
private member data.

Local preview shots from this branch (website, desktop + mobile) live in
`/workspace/barksbuds-assets/handoff/shots/` and can stand in for layout
review, but the stores want device-frame sizes from the running app.

## Apple (required sizes)

Use the latest phones Apple lists in App Store Connect. Typical set:

- 6.7" iPhone (e.g. 1290 × 2796)
- 6.5" iPhone (e.g. 1284 × 2778) if still requested
- 13" iPad (e.g. 2048 × 2732) if you also ship iPad (this build is iPhone
  first; an iPad screenshot is only needed if the app is offered there)

Upload 3–10 shots per size. Suggested order:

1. Dog run map, "Nearest first" after the owner has allowed location
2. A run page with "Recently here" (dog name + photo only)
3. Meetups month calendar
4. A meetup detail the demo account RSVPed to
5. My dogs — Lily's profile, photo manager with Take a photo / Choose from
   library
6. Local picks grouped by town
7. Account page showing notifications Off, with the Turn on button visible

Captions, optional, short: "Find a dog run near you", "See who's at the run",
"Meetups on a calendar", "Your dog's profile".

## Google Play (required sizes)

- Phone: at least two, 16:9 or 9:16, between 320 px and 3840 px per side
- Tablet (optional): 7" and 10" if you want larger layouts featured

Use the same seven scenes as above, cropped to 9:16 for phones.

## Feature graphic (Google, 1024 × 500)

Jack logo on the cream `#FFF8EA` background, wordmark "BarksBuds", tagline
"A group of friends that love their dogs". No other dogs, no photos of
people.
